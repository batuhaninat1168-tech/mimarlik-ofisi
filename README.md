# 🏛️ Aura Mimarlık - Modern Web Sitesi

Modern mimarlık ofisleri ve tasarım stüdyoları için hazırlanmış, mobil uyumlu ve açılır galeri pencereli (modal lightbox) tek sayfalık vitrin sitesi.

## 🚀 Canlı Demo
Siteyi canlıda incelemek için:  
👉 **[https://aura-mimarlik-studio.netlify.app/](https://aura-mimarlik-studio.netlify.app/#)**

## 🛠️ Kullanılan Teknolojiler
* **HTML5:** Semantik web iskeleti
* **Tailwind CSS:** Modern utility-first arayüz tasarımı
* **Vanilla JavaScript:** Açılır galeri penceresi (Modal Lightbox)
* **Netlify:** Bulut barındırma ve canlı yayınlama

## ✨ Öne Çıkan Özellikler
* Mobil ve masaüstü tam uyumluluk (Responsive)
* Tıklanabilir görsel galeri modalları
* Hızlı yüklenen hafif yapı
